# Reference: 데이터 매핑 · 엔티티 해소 · 액션(write-back)

객체·링크(→ `modeling-primitives.md`)를 실제 데이터에 잇고(매핑), 온톨로지를 **읽기 모델에서 행동의 시스템으로** 만든다(액션).

## 1. 백킹 데이터셋 (Backing Dataset)

각 객체 타입·링크 타입은 하나 이상의 **원천 데이터셋**에 뒷받침된다.

- **객체 ← 데이터셋**: 객체의 각 인스턴스는 백킹 테이블의 행(또는 여러 테이블의 결합)에서 온다.
- **속성 ← 컬럼(변환 포함)**: 속성은 원천 컬럼을 직접/가공해 채운다.
- **링크 ← 조인/조인 테이블**: 링크는 백킹 데이터셋 간 조인(또는 N:M 조인 테이블)으로 실현.
- **신선도**: 백킹 데이터셋의 갱신 주기가 곧 온톨로지의 신선도. 물리 파이프라인(→ `data-engineer` 플러그인)이 이를 공급.

**매핑 명세에 담을 것**: 객체 타입 → 백킹 데이터셋, 기본키 컬럼, 속성↔컬럼 매핑(변환식), 링크 → 조인 조건·카디널리티.

## 2. 엔티티 해소 (Entity Resolution)

여러 원천에 흩어진 **같은 실체**를 하나의 객체 인스턴스로 판별·통합한다. 온톨로지 품질의 핵심이며, 매핑의 일부로 **먼저** 설계한다(나중으로 미루지 않는다).

- **결정적(deterministic) 매칭**: 공유 키·표준 식별자(사업자번호·이메일 정규화)로 정확 매칭.
- **확률적(probabilistic)/퍼지 매칭**: 이름·주소 유사도 등 스코어 기반. 임계값·리뷰 큐 설계.
- **골든 레코드 / survivorship**: 충돌하는 속성값 중 무엇을 채택할지 규칙(최신·신뢰 원천 우선 등).
- **안정적 객체 키**: 해소 결과에 부여하는 안정 식별자(원천이 바뀌어도 유지). 링크·액션이 이 키를 참조.

**함정**: 엔티티 해소를 매핑 뒤로 미루면 중복 객체·깨진 링크가 그래프 전체로 번진다.

## 3. 액션 & 운영 계층 (Actions / write-back)

온톨로지를 "조회용 데이터 모델"로 두면 절반만 쓴 것이다. **액션**은 사용자가 온톨로지 위에서 내린 결정·상태 변화를 **원천/온톨로지에 되쓰는(write-back)** 장치다 — 읽기 모델을 **행동의 시스템(system of action)**으로 만든다.

- **액션 정의**: 이름(도메인 동사), 대상 객체/링크, 입력 파라미터, **효과(생성/수정/링크 변경)**, **검증 규칙**, **권한**.
- **write-back 경로**: 액션 결과를 (a) 온톨로지 상태, (b) 원천 시스템(운영 DB·업무 앱)으로 반영. 일관성·트랜잭션 경계 설계.
- **함수/자동화 연계**: 액션이 계산·모델·외부 API를 호출할 수 있음(예: "재주문 승인" → 재고 확인 → 발주 생성).
- **감사(audit)**: 누가·언제·무엇을 바꿨는지 기록. 되돌리기/추적 가능성.
- **피드백 루프**: 액션의 결과가 다시 백킹 데이터·온톨로지로 흘러들어 다음 결정의 입력이 된다.

**설계 지침**
- **액션을 먼저 생각한다**: "이 온톨로지가 지원할 결정/행동은 무엇인가"에서 출발하면 객체·링크·속성의 필요 범위가 정해진다(액션 지향 모델링).
- 검증·권한을 액션에 내장(불변식을 UI가 아니라 모델 층에서 보장).
- write-back의 실패·부분성공을 다룰 트랜잭션/보상 전략을 명시.

## 4. 읽기 모델 → 행동 시스템 요약

```
원천 데이터 ──매핑·엔티티 해소──▶ 온톨로지(객체·링크 그래프)
      ▲                                   │
      │                                   ▼ 액션(검증·권한)
      └──────── write-back ◀────── 결정·행동
```

이 루프가 온톨로지를 정적 카탈로그가 아니라 **운영 시스템**으로 만든다.

## 5. 흔한 anti-pattern

- **엔티티 해소 지연**: 중복·깨진 링크가 그래프로 전파.
- **읽기 전용 온톨로지**: 액션/write-back이 없어 "예쁜 뷰"에 머묾.
- **UI 층 검증**: 불변식을 액션(모델 층)이 아니라 화면에만 두어 우회 가능.
- **매핑 변환의 블랙박스화**: 속성↔컬럼 변환·조인 조건이 문서화되지 않아 리니지 단절.
